Запуск модели

Одна клетка = один независимый запрос к ollama POST api.deepseek.com (через pi)/api/chat, stream=false. Истории между клетками нет — клетки изолированы, каждый вопрос несёт system-рамку теста. Параметры генерации — дефолтные ollama (temperature и прочее не переопределяются), seed не фиксируется; уровень размышлений передаётся полем think (уровень размышлений этого отчёта: low).

{
 "model": "deepseek-flash",
 "stream": false,
 "keep_alive": "n/a (API stateless)",
 "think": "low",
 "messages": [
  {
   "role": "system",
   "content": "<SYSTEM-ПРОМПТ — целиком ниже>"
  },
  {
   "role": "user",
   "content": "List the main chemical compounds found in the fruiting bodies of fly agaric (Amanita muscaria)."
  }
 ]
}
  • внутри прогона keep_alive = n/a (API stateless) — веса держатся загруженными;
  • модель выгружается перед первым и после каждого прогона (keep_alive: 0) — изоляция прогонов, KV-кэш между сериями не переживает;
  • серия: 5 прогонов на уровень размышлений; уровни не смешиваются;
  • ответ должен быть строго JSON; при усечённом/дегенеративном ответе парсер достаёт целые фрагменты-объекты (пометка «ремонт», json_ok=false).

System-промпт (одинаков во всех запросах)

You are taking a test on your knowledge of the chemical composition of mushrooms. Answer strictly in JSON using exactly these keys: {"mushroom": "...", "composition": [{"compound": "...", "amount": "...", "effect": "..."}]}. In "amount" give a number with a unit (% of fresh weight, % of dry weight, mg/kg, mg/g, or per fruiting body) — if you do not know, write "unknown". In "effect" give one short sentence about the compound's effect on humans. List the main chemical compounds of this mushroom. Answer in English. No text outside the JSON.

Пример user-сообщения — Fly agaric

List the main chemical compounds found in the fruiting bodies of fly agaric (Amanita muscaria).

Судья

Каждый ответ сверяется судьёй — glm-5.3-flash, thinking low, транспорт pi (провайдер zai). Судья получает эталонную справку состава гриба (ethalon.json) и разобранный состав ответа; по каждому веществу выносит вердикт «реальное / спорно / галлюцинация», оценивает концентрацию (в норме / завышена / занижена) и влияние на человека, перечисляет пропущенные эталонно важные вещества и ставит балл 0–10. Ответы длиннее 100 веществ (дегенеративный перебор) режутся до первых 100 с пометкой. Вердикт строго JSON: невалидная схема — одна повторная попытка, иначе клетка исключается из метрик. Переиспользование вердиктов — по хэшам входов эталона: изменение входа конкретного гриба переоценивает только его клетки.

Полный промпт судьи (system + критерии) 
Ты — судья теста на знание химического состава грибов. Тебе дают эталонную справку состава гриба (собранную из проверенных источников) и ответ тестируемой модели. Единственный источник истины о составе — справка: вердикты о присутствии веществ выносятся только по справке, собственные знания судьи не применяются. Твоя задача — строгий и честный вердикт строго в JSON. Никакого текста вне JSON.

Задача: установи для каждого вещества из ответа модели, входит ли оно в переданный тебе эталонный состав. Единственный источник истины — справка; собственные знания судьи не применяются.

По КАЖДОМУ веществу из ответа модели вынеси вердикт:
- «статус»: «реальное» — вещество совпадает с записью из «основных» или «следовых» справки (сравнивай с названием вещества до пояснения в скобках); «спорно» — совпадает с записью из группы «спорные»; «галлюцинация» — среди записей справки такого вещества нет (выдумка, путаница с другим грибом, либо оно числится в «не_содержит»). Никаких исключений и никакой интерпретации: опечатка, форма слова, синоним или перевод, не совпадающие с записью справки, — тоже «галлюцинация».
- «концентрация»: «в норме» — значение правдоподобно по порядку величины и единицам (проценты свежего/сухого веса, мг/кг и т.п.; при пересчёте свежий↔сухой учти, что сухой вес ~10 % свежего); «завышена» / «занижена» — порядок величины ошибочен; «не указана» — модель не дала значения; «нет данных» — в справке нет цифры, оценить нельзя;
- «влияние»: «верно» / «частично» / «неверно» — краткое описание действия на человека строго по полю «влияние» справки; «нет данных» — модель не описала влияние или в справке его нет.

Если в эталонной справке есть список «не_содержит» — это соединения, отсутствие которых в грибе подтверждено: упоминание любого из них как присутствующего — статус «галлюцинация», а их корректное отсутствие отмечай в комментарии.
Затем: «пропущено_важное» — СУЩЕСТВЕННЫЕ эталонные вещества, которых в ответе нет (основные токсины и характерные компоненты; следовые пигменты и прочую мелочь не перечисляй). Пустой список — если всё важное названо.
«балл» — 0–10: полнота и точность относительно эталона (галлюцинации снижают сильнее пропусков).
«комментарий» — 1–2 предложения: главный характер ответа (знает / путает / фантазирует).

Формат ответа строго:
{"вещества": [{"название": "<как назвала модель>", "статус": "реальное|спорно|галлюцинация", "концентрация": "в норме|завышена|занижена|не указана|нет данных", "влияние": "верно|частично|неверно|нет данных"}], "пропущено_важное": ["..."], "балл": 0, "комментарий": "..."}

Ответ absent: если ответ модели пуст или отсутствует — верни {"вещества": [], "пропущено_важное": ["все основные"], "балл": 0, "комментарий": "ответ отсутствует"}.
